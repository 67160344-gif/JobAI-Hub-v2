# JobAI Hub v2.2

แพลตฟอร์มหางานและสมัครงานออนไลน์ด้วย AI — ผู้หางานอัปโหลด Resume ให้ระบบวิเคราะห์ จับคู่งานตามทักษะ สมัครงานพร้อม Cover Letter อัตโนมัติ ฝึกสัมภาษณ์กับ AI Coach และติดตามสถานะ ส่วนนายจ้างลงประกาศงานและจัดการผู้สมัครได้เอง

**Stack:** Node.js 20 + Express • PostgreSQL 15 • JWT + bcrypt • OpenAI Responses API (ไม่บังคับ) • Poppler + Tesseract OCR • Tailwind CSS

---

## รันด้วย Docker (แนะนำ)

1. คัดลอก `.env.example` เป็น `.env` แล้วตั้งค่า `JWT_SECRET` (สร้างค่าสุ่มได้ด้วยคำสั่งด้านล่าง)
   ```bash
   cp .env.example .env
   node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
   ```
   ถ้าต้องการใช้ AI จริง ให้ใส่ `OPENAI_API_KEY` ด้วย (ไม่ใส่ก็ใช้งานได้ครบทุกฟีเจอร์ในโหมดสำรอง)
2. รัน
   ```bash
   docker compose up --build
   ```
3. เปิด http://localhost:3000

> **เคยรันเวอร์ชันเก่ามาก่อน?** ระบบจะอัปเกรดฐานข้อมูลเดิมให้อัตโนมัติ (เพิ่มคอลัมน์ ซ่อมวันนัดสัมภาษณ์ เติมรีวิวตัวอย่าง)
> แต่ถ้าอยากได้ข้อมูล Demo ที่สะอาดก่อนพรีเซนต์ ให้รัน `docker compose down -v` ก่อน แล้วค่อย `docker compose up --build`

### รันแบบไม่ใช้ Docker
ต้องมี Node.js 20+ และ PostgreSQL ที่สร้างฐานข้อมูลไว้แล้ว
```bash
npm install
DB_HOST=localhost DB_USER=admin DB_PASSWORD=password123 DB_NAME=jobai_db JWT_SECRET=<ค่าสุ่ม> npm start
```
(OCR สำหรับ PDF แบบสแกนจะทำงานเมื่อเครื่องมี `pdftoppm` และ `tesseract` ภาษาไทยเท่านั้น)

## ฟีเจอร์

### ผู้หางาน
- **วิเคราะห์ Resume** PDF / DOCX / TXT (PDF แบบสแกนใช้ OCR ไทย+อังกฤษ) → คะแนน 0–100, ทักษะ, ปีประสบการณ์, สายงาน, ข้อเสนอแนะ, รายงานพิมพ์/บันทึกเป็น PDF
- **จับคู่งาน** % Match เฉพาะบุคคล คำนวณจากทักษะที่ตรง + ประสบการณ์ขั้นต่ำของงาน
- **สมัครงาน** พร้อม Cover Letter อัตโนมัติ ระบบเก็บสำเนา Resume ณ วันที่สมัครให้นายจ้าง
- **AI Interview Coach** คำถามทั่วไปใช้ได้ทุกอาชีพ (สุ่มจากคลัง 12 หมวด เช่น จุดแข็ง ทีมเวิร์ก การแก้ปัญหา ความกดดัน การบริการลูกค้า จริยธรรม) + คำถามเฉพาะตำแหน่งเมื่อเลือกงาน ประเมิน Clarity / Problem Solving / Teamwork + คำแนะนำ เก็บประวัติการฝึก รองรับพูดตอบ (Chrome/Edge)
- **ติดตามผล** Kanban 5 สถานะ (สมัคร → สัมภาษณ์ → Offer → ได้งาน / ไม่ผ่าน), ถอนใบสมัคร, รีวิวบริษัท, แจ้งเตือนอัปเดตทุก 30 วินาที

### นายจ้าง
- สมัครบัญชีนายจ้างได้เอง (เลือก "นายจ้าง / HR" ตอนสมัคร)
- ลง / แก้ไข / ปิด / เปิดประกาศงานอีกครั้ง
- ดูใบสมัคร Cover Letter Portfolio และเปิดไฟล์ Resume, กรองตามตำแหน่ง
- เปลี่ยนสถานะผู้สมัคร (นัดสัมภาษณ์พร้อมวันเวลา) → ผู้สมัครได้รับแจ้งเตือนอัตโนมัติ

### AI จริง vs โหมดสำรอง
| ฟีเจอร์ | มี `OPENAI_API_KEY` | ไม่มี key / เรียก AI ไม่สำเร็จ |
|---|---|---|
| วิเคราะห์ Resume | OpenAI Responses API (Structured Output) | Rule-based: ตรวจทักษะ 25 หมวด ช่วงปีทำงาน (รองรับ พ.ศ.) ตัวเลขวัดผล ข้อมูลติดต่อ |
| คำถามสัมภาษณ์ | สร้างคำถามทั่วไปหลายหมวด ไม่ซ้ำแต่ละครั้ง | สุ่มจากคลังคำถาม 12 หมวด (~40 ข้อ) |
| ประเมินคำตอบ | ให้คะแนนและคำแนะนำเฉพาะคำตอบ | ตรวจโครงสร้าง STAR, คีย์เวิร์ด, ตัวเลข, ความยาว |
| Cover Letter | เขียนจากข้อมูล Resume จริง | เทมเพลตที่ดึงทักษะที่ตรงกับงาน |

ทุกผลลัพธ์มีป้ายบอกว่า **"AI จริง"** หรือ **"โหมดสำรอง"** เสมอ ถ้า AI ล่มระหว่างใช้งาน ระบบจะสลับไปโหมดสำรองให้อัตโนมัติ (ไม่ error)
การใช้ OpenAI API มีค่าใช้จ่ายตามบัญชีของคุณ

## โครงสร้างโปรเจกต์
```
server.js            Express API + เชื่อมฐานข้อมูล + seed ข้อมูล demo
lib/analyzer.js      Rule-based engine (วิเคราะห์ Resume, Match, ประเมินคำตอบ, คำถาม, Cover letter)
lib/ai.js            OpenAI Responses API client (ใช้ fetch ในตัว ไม่ต้องลงแพ็กเกจเพิ่ม)
lib/report.js        สร้างรายงานผลวิเคราะห์ Resume (HTML พร้อมพิมพ์เป็น PDF)
public/              หน้าเว็บ (index.html, app.js) — เป็นโฟลเดอร์เดียวที่เปิดให้เข้าถึงจากเบราว์เซอร์
samples/             Resume ตัวอย่างสำหรับ demo และ seed
test/                Unit test ของ analyzer  (npm test)
docs/legacy-data.json ข้อมูลจากเวอร์ชัน demo เดิม (เก็บไว้อ้างอิงเท่านั้น ไม่ได้ใช้งาน)
```

## API หลัก
| Method | Path | สิทธิ์ |
|---|---|---|
| POST | `/register`, `/login` | ทุกคน |
| GET | `/me`, `/api/notifications`, `/api/reviews` | ผู้ใช้ที่ login |
| POST | `/change-password` | ผู้ใช้ที่ login (token เก่าทุกเครื่องใช้ไม่ได้ทันที) |
| GET/POST | `/api/resume`, `/api/resume/analyze`, `/api/resume/report` | ผู้หางาน |
| GET/POST/DELETE | `/api/jobs`, `/api/applications`, `/api/cover-letter` | ผู้หางาน |
| GET/POST | `/api/interview/questions`, `/api/interview/evaluate`, `/api/interview/history` | ผู้หางาน |
| GET/POST/PATCH | `/api/employer/jobs`, `/api/employer/applications/...` | นายจ้าง |
| GET | `/api/status` | ทุกคน (บอกว่าเปิด AI หรือไม่) |

## ความปลอดภัย
- เสิร์ฟเฉพาะโฟลเดอร์ `public/` — ไฟล์โค้ด, `docker-compose.yml`, `.env` ไม่ถูกเปิดเผย
- บังคับ `JWT_SECRET` ใน production (`NODE_ENV=production`) ถ้าไม่ตั้งในโหมด dev ระบบจะสุ่มให้ชั่วคราว
- ตรวจสิทธิ์ตามบทบาททุก endpoint, ตรวจข้อมูลขาเข้า, จำกัดการเดารหัสผ่าน (10 ครั้ง/15 นาที)
- ฐานข้อมูลไม่เปิดพอร์ตออกนอกเครื่องโดยค่าเริ่มต้น, container backend รันด้วย user ที่ไม่ใช่ root
- Error ของ API ไม่ทำให้เซิร์ฟเวอร์ล่ม และ Docker จะรีสตาร์ทให้อัตโนมัติถ้าเกิดปัญหา

## ข้อจำกัดที่ควรรู้
- หน้าเว็บโหลด Tailwind, Font Awesome และฟอนต์จาก CDN → **เครื่องที่ใช้พรีเซนต์ต้องต่ออินเทอร์เน็ต** (ถ้าไม่มีเน็ตระบบยังทำงานได้แต่หน้าตาจะไม่มีสไตล์)
- รายงาน Resume สร้างจาก backend เป็นหน้า HTML แล้วบันทึกเป็น PDF ผ่านหน้าต่างพิมพ์ของเบราว์เซอร์
- การพูดตอบสัมภาษณ์ใช้ Web Speech API ของเบราว์เซอร์ (Chrome / Edge)

## แก้ปัญหาเบื้องต้น
| อาการ | วิธีแก้ |
|---|---|
| พอร์ต 3000 ถูกใช้อยู่ | แก้ `ports` ใน `docker-compose.yml` เป็น `"3001:3000"` แล้วเปิด http://localhost:3001 |
| Login ได้แต่ข้อมูลแปลก/ไม่ตรง demo | `docker compose down -v` แล้ว `docker compose up --build` เพื่อเริ่มฐานข้อมูลใหม่ |
| ต้อง login ใหม่ทุกครั้งที่รีสตาร์ท | ยังไม่ได้ตั้ง `JWT_SECRET` ใน `.env` |
| ป้ายขึ้น "โหมดสำรอง" ทั้งที่ใส่ key แล้ว | ดู log ด้วย `docker compose logs backend` — key ผิด / model ไม่ถูกต้อง / เครดิตหมด ระบบจะ log สาเหตุไว้ |
