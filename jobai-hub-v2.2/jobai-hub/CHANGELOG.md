# Changelog

## v2.2.0 (2026-10-23)

### ฟีเจอร์ที่เพิ่ม / ทำให้ใช้งานได้จริง
- เชื่อม **OpenAI Responses API** (Structured Outputs) สำหรับวิเคราะห์ Resume, สร้างคำถามสัมภาษณ์, ประเมินคำตอบ และเขียน Cover Letter — มีโหมดสำรองแบบ rule-based ทุกฟีเจอร์ และป้าย "AI จริง / โหมดสำรอง" บน UI
- เพิ่ม endpoint `POST /api/interview/evaluate` (เดิมไม่มี ทำให้แท็บ AI โค้ชใช้ไม่ได้), `GET /api/interview/questions`, `GET /api/interview/history` และตาราง `interview_answers`
- **% Match คำนวณจริง** จากทักษะใน Resume เทียบกับ tag ของงาน + ประสบการณ์ขั้นต่ำ (เดิมเป็นค่าคงที่)
- วิเคราะห์ Resume ได้ปีประสบการณ์จริง (รองรับ พ.ศ. / ช่วงปี / "ปัจจุบัน"), สายงานหลัก, ข้อเสนอแนะตามสิ่งที่ขาด
- รายงานผลวิเคราะห์ Resume สร้างจาก backend (`GET /api/resume/report`) พร้อมพิมพ์/บันทึกเป็น PDF
- คำถามสัมภาษณ์เป็นแบบทั่วไปใช้ได้ทุกอาชีพ สุ่มจากคลัง 12 หมวด กด "สุ่มชุดใหม่" ได้ และเพิ่มคำถามเฉพาะตำแหน่งเมื่อเลือกงาน (เดิมล็อกสาย UX/UI)
- Login แยกต่อแท็บ เปิดแท็บ HR กับผู้หางานพร้อมกันได้
- Employer: สมัครบัญชีนายจ้างเองได้, แก้ไข/เปิดประกาศอีกครั้ง, ดู Cover Letter และ Portfolio, กรองผู้สมัคร, เลือกวันเวลานัดสัมภาษณ์, สถานะ "ไม่ผ่าน", แจ้งเตือนเมื่อมีผู้สมัครใหม่/ถอนใบสมัคร
- ผู้หางานได้รับแจ้งเตือนเมื่อนายจ้างเปลี่ยนสถานะ (ตรวจแจ้งเตือนใหม่ทุก 30 วินาที)
- เก็บสำเนา Resume ณ วันที่สมัครไว้กับใบสมัคร นายจ้างจึงเห็นไฟล์ที่ใช้สมัครจริง
- Resume ตัวอย่างใน `samples/` และ unit test (`npm test`)

### แก้บัค
- เมนูมือถือใช้ไม่ได้ (escape `\"` ผิดใน HTML) และไม่มีเมนู Employer บนมือถือ
- การ์ดนัดสัมภาษณ์แสดงวันที่ 1970 (seed และการเปลี่ยนสถานะไม่ได้ตั้ง `interview_at`)
- ผู้ใช้ใหม่เห็นการ์ด "วิเคราะห์เรียบร้อย 0/100 / Invalid Date" → เปลี่ยนเป็นหน้าว่างพร้อมปุ่มอัปโหลด
- เซิร์ฟเวอร์ล่มเมื่อ async route เกิด error (เช่น id ไม่ใช่ตัวเลข) → มี error handler กลาง
- ชื่อไฟล์ที่มี `%` ทำให้อัปโหลดพัง (decode ซ้ำ)
- OCR ใช้ `execFileSync` บล็อกทั้งเซิร์ฟเวอร์ → เปลี่ยนเป็น async
- ฟอร์มสมัครงานใส่ชื่อ/อีเมลของสมชายให้ทุกคน → ใช้ข้อมูลของบัญชีที่ login
- ผู้หางานเปลี่ยนสถานะใบสมัครตัวเองได้ (ปุ่ม "จำลอง HR") → ลบออก ให้นายจ้างเป็นคนเปลี่ยน
- รีวิว 0 ดาวได้ / rating เป็น null ทำให้ส่วนรีวิวพัง, ไม่มีรีวิวตั้งต้น, ไม่มีข้อความเมื่อยังไม่มีรีวิว
- ตัวเลขแจ้งเตือนค้างหลัง logout, แบนเนอร์ Employer ซ้ำ 2 อัน, รูปโปรไฟล์เป็นรูปคนเดียวกันทุกบัญชี
- token หมดอายุระหว่างใช้งานแล้วหน้าเว็บค้าง → เด้งไปหน้า login พร้อมแจ้งเตือน
- ข้อความ NUL ใน PDF ทำให้บันทึกลง PostgreSQL ไม่ได้

### ความปลอดภัย
- เสิร์ฟเฉพาะโฟลเดอร์ `public/` (เดิมเปิดทั้งโปรเจกต์ รวม `server.js`, `docker-compose.yml`, `data.json`)
- ไม่ใช้ JWT secret ค่า default ที่เดาได้ (บังคับใน production, สุ่มชั่วคราวในโหมด dev)
- ตรวจสิทธิ์ตามบทบาท (ผู้หางาน/นายจ้าง) ทุก endpoint, ลบ `GET /users` ที่เปิดอีเมลทุกคน
- ตรวจข้อมูลขาเข้าฝั่ง server (รหัสผ่าน ≥ 8 ตัว, อีเมล, สถานะ, ไฟล์ PDF/DOCX จริง, ความยาวข้อความ)
- เปลี่ยนรหัสผ่านแล้ว token เก่าใช้ไม่ได้ทันที, จำกัดการเดารหัสผ่าน
- `.dockerignore` (ไม่คัดลอก `.env`), ไม่เปิดพอร์ตฐานข้อมูล, container รันด้วย user `node`, healthcheck, `restart: unless-stopped`
- ลบ bind mount `.:/app` + anonymous volume `node_modules` ที่ทำให้แพ็กเกจเก่าค้างเมื่อ build ใหม่
